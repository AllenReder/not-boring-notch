# Occurrences of the old brand that scripts/check-branding.sh is told to accept.
#
# Format, one entry per line:
#
#   kind | path glob | fragment | reason
#
#   kind = path   the path itself may contain the old brand. `fragment` is unused (`-`).
#   kind = line   occurrences of `fragment` may appear in any file the path glob matches.
#   kind = file   the whole file may contain the old brand, path and contents alike.
#
# A `line` fragment is stripped from the line before the line is tested, so the entry excuses
# exactly the text it names and nothing else. Editing the exempted text without editing the
# entry turns the exemption back into a violation. A `file` entry is for the few files that are
# made of the token itself; it is a blunt exemption, which is why those files are named here
# with a reason instead of being excused by a list hidden inside the gate.
#
# This file is never scanned. It is made of the token — every entry names a fragment to excuse —
# so it would fail on itself.
#
# This file is the answer to "why does this file still say boring?". Every entry needs a reason
# a reader can disagree with; "it is annoying to fix" is not one. The test for a new entry is not
# whether the old name is present — it plainly is — but whether renaming it would be wrong:
# because the name belongs to somebody else, because the string is written to disk under it,
# because this is a record of what was decided at the time, or because the file exists to talk
# about the token at all. Anything else is a rename that has not happened yet.
