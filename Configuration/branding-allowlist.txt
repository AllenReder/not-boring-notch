# Occurrences of the old brand that scripts/check-branding.sh is told to accept.
#
# Format, one entry per line:
#
#   kind | path glob | fragment | reason
#
#   kind = path   the path itself may contain the old brand. `fragment` is unused (`-`).
#   kind = line   occurrences of `fragment` may appear in any file the path glob matches.
#
# The fragment is stripped from the line before the line is tested, so an entry excuses
# exactly the text it names and nothing else. Editing the exempted text without editing the
# entry turns the exemption back into a violation.
#
# There are two sections. The first is permanent and is why this file exists at all. The
# second is a transition ledger: it exists because the gate had to be able to run, and fail,
# before the rename happened. Every entry in it is deleted by the commit that lands the
# rename, and nothing may be added to it.
#
# An entry in the permanent section needs a reason a reader can disagree with. "It is
# annoying to fix" is not a reason.
